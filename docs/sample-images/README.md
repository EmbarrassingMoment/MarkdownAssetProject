# Sample Images

Dummy gauge images for verifying the Markdown editor's image preview feature.
Import them into the Content Browser (drag & drop) and reference the resulting
texture assets from a Markdown asset, e.g. `![HP gauge](/Game/Textures/T_GaugeBar)`.

| File | Size | Purpose |
|---|---|---|
| `T_GaugeBar.png` | 512×64 | Basic embedding (power-of-two size, opaque) |
| `T_GaugeCircle.png` | 256×256 | Alpha / transparency handling |
| `T_GaugeSegment.png` | 500×60 | Non-power-of-two (NPOT) size |
