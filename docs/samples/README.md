# Sample Markdown Files

Markdown documents that walk through the plugin's features in the editor.
Drag a file into the Content Browser to import it as a `UMarkdownAsset`, then
open the asset and follow the instructions inside.

| File | Purpose |
|---|---|
| `MD_FeatureTour_1_5.md` | Verifies the 1.5.0 features: Editor Preferences (theme, refresh delay, font size, paste folder), light / dark preview themes, Find & Replace, Content Browser drag & drop links, standalone HTML export, and the preview texture cache |

The tour references assets that ship with this project (`MD_Sample`,
`BP_LinkTest`, `/Game/Textures/T_GaugeCircle`, `/Game/Textures/T_GaugeSegment`).
When importing the file into another project, import the images from
[`docs/sample-images`](../sample-images/README.md) first or adjust the paths.
