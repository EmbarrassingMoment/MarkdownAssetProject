# サンプル Markdown ファイル

エディタ上でプラグインの機能を順に確認するための Markdown ドキュメントです。
ファイルをコンテンツブラウザにドラッグすると `UMarkdownAsset` としてインポートされるので、
アセットを開いて本文の手順に従ってください。

| ファイル | 目的 |
|---|---|
| `MD_FeatureTour_1_5.md` | 1.5.0 の機能確認: エディタ設定（テーマ、更新遅延、フォントサイズ、貼り付け先フォルダ）、ライト / ダークのプレビューテーマ、検索と置換、コンテンツブラウザからのドラッグ＆ドロップによるリンク挿入、スタンドアロン HTML エクスポート、プレビュー用テクスチャキャッシュ |

ツアー内ではこのプロジェクトに同梱のアセット（`MD_Sample`、`BP_LinkTest`、
`/Game/Textures/T_GaugeCircle`、`/Game/Textures/T_GaugeSegment`）を参照しています。
別プロジェクトにインポートする場合は、先に [`docs/sample-images`](../sample-images/README.md)
の画像をインポートするか、パスを読み替えてください。
